# guesser_knower_test_battery_dogs
 This study assessed the construct validity and test-retest reliability of the "Guesser-Knower" task as typically implemented with dogs. 
 The R script for analyses is the file called "guesser_knower_dogs_analyses.Rmd"; the workspace is in the folder "workspace". 
 The data are in the folder "data": the file "gk_test_data.csv" contains all test data; the other file contains the data for calculating inter-observer reliability. 
Data can be reused acknowledging the copyright of the authors of the study.
